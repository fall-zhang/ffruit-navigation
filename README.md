## 鲜果导航

一些计算机相关知识点

- 提醒用户不要在不安全的网站上输入 账号密码等相关隐秘信息
- 提醒用户注意输入域名的正确性
- 输入框

可以一组一组地进行制定

## 项目结构

- nav-admin 应用后端管理页面
  - 控制 tag
  - 控制所有导航
  - 控制所有建议
  - 控制所有言语

- nav-main
  - 导航应用

- nav-server 后端服务
  - mongodb 数据库
  - 获取 tag 等信息
